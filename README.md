# Java Calculator

A simple **console-based calculator** built using Java. This application allows users to perform basic arithmetic operations through a menu-driven interface. It is a beginner-friendly project that demonstrates fundamental Java programming concepts.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Menu-driven interface
* User input using the `Scanner` class
* Error handling for division and modulus by zero

## Technologies Used

* Java
* Scanner Class
* Object-Oriented Programming (OOP) Basics

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/java-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd java-calculator
   ```

3. Compile the program:

   ```bash
   javac Calculator.java
   ```

4. Run the program:

   ```bash
   java Calculator
   ```
